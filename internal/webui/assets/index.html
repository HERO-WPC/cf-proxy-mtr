线路跟踪设置
跟踪是独立的一步：先在上面测出延迟，再用下面的条件挑一批，点「开始跟踪线路」。 这些参数只影响跟踪，不影响 TCP 测量。
按"线路的 IP 段"（来自 RouteViews BGP 数据）判断路径走了 CN2 / 163 / CMI 等哪几条线路。 首次使用会抓取约 1.7 MB 前缀并缓存 7 天，之后完全离线。 勾上它就可以把上面的数据源设成 disable-geoip，彻底不依赖任何限流的 GeoIP 服务。
与程序同目录、或放在 data/bin 下的 nexttrace 会被优先使用； 自定义路径（上面的「NextTrace 路径」）优先级最高，不会被自动下载覆盖。 自动下载取固定版本 v1.7.3，且只提供 nexttrace 本体—— Windows 上 TCP/UDP 模式还需要 WinDivert（发布物里不含）。
