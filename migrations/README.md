# migrations/

Phase 3（SQLite）阶段该目录的定位如下：

SQL 迁移语句以**字符串常量**的形式维护在 Go 源码中
（`internal/storage/migrations.go`），这样：

1. 迁移随二进制一起发布，不需要在运行时定位 SQL 文件；
2. 数据库版本表与迁移逻辑在同一个包里，容易测试；
3. 单文件分发（Windows 双击 exe）不会因为缺少 SQL 文件而失败。

本目录用于存放：

- 迁移说明与设计记录（例如为什么某个索引存在、某次字段变更的原因）；
- 需要人工审查的、较大规模的迁移脚本草稿；
- 数据库结构的变更历史。

Phase 0 尚未涉及任何数据库逻辑，这里只占位。
